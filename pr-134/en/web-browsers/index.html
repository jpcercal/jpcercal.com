On April 21, 1993, Marc Andreessen, a computing student, perhaps unintentionally kick-started the popularization of the internet by creating a browser called Mosaic 1.0. Tim Berners-Le, the inventor of the World Wide Web, popularly known as www, had already developed a browser, but Mosaic was the first to work in a fully graphical way.

Following the success of Mosaic, Andreessen founded Netscape in 1994. By distributing an improved version of Mosaic, named Netscape Navigator, the company came to dominate the browser market.

A Web Browser is a program that interprets HTML, CSS, Javascript files, among others.
