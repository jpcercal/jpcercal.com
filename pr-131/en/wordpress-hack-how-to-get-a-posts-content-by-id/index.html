WordPress Hack: How to get a Post's content by ID

PHP João Paulo Cercal Learn to retrieve a post's content (post_content) in Wordpress based on a post's ID. Get to know the function that can help you with this task. https://staging.jpcercal.com/pr-131/en/wordpress-hack-how-to-get-a-posts-content-by-id/index.svg https://staging.jpcercal.com/pr-131/en/wordpress-hack-how-to-get-a-posts-content-by-id/index.dark.svg en post

When you’re building a theme for WordPress, you may need to get the content of a specific post using the ID as a filter. Most of the time you get a post’s content through the get_post_content function inside a Loop.

However, when you need to retrieve a post’s information outside the loop context or at a separate point in the application, the best solution is to use the get_post_field('field-name'), $postId) function.

Right below you can check an example of retrieving a post’s content by ID:

1
2
3

<?php

echo get_post_field('post_content', $post_id);

You can find more details about this function in the official WordPress documentation.
