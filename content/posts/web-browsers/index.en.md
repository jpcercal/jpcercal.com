On April 21, 1993, _Marc Andreessen_, a computing student, perhaps unintentionally kick-started the
popularization of the internet by creating a browser called **Mosaic 1.0\.** _Tim Berners-Le, the inventor of the World Wide Web_,
popularly known as **www**, had already developed a browser, but _Mosaic_ was the first to
work in a fully graphical way.

Following the success of _Mosaic_, _Andreessen_ founded **Netscape** in 1994. By distributing an improved version of
_Mosaic_, named _Netscape Navigator_, the company came to dominate the browser market.

A Web Browser is a program that interprets HTML, CSS, Javascript files, among others.
