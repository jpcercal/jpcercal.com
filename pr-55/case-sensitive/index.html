“Case sensitive” é um termo que indica que um texto é sensível ao tamanho, ou seja, faz distinção entre o tamanho das letras (maiúscula, minúscula).

Veremos como funciona na prática analizando as situações abaixo:

Case Sensitive

texto é diferente de Texto, pois a segunda palavra inicia-se com uma consoante capitalizada.

Case Insensitive

texto é igual à Texto, não há diferenças entre o tamanho das letras.

Complementarmente utiliza-se um conceito de juntar as palavras e capitalizar as letras que antecedem cada palavra chamado CamelCase.
