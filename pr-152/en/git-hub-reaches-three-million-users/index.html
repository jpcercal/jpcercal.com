Git Hub reaches 3 million users

News João Paulo Cercal The web hosting service Git Hub announced that it passed the three-million-user mark. Check out this news and get to know GitHub. https://staging.jpcercal.com/pr-152/en/git-hub-reaches-three-million-users/index.svg https://staging.jpcercal.com/pr-152/en/git-hub-reaches-three-million-users/index.dark.svg en post

The web hosting service GitHub announced that it passed the three-million-user mark.

This site has social network features such as feeds, followers, wiki and a graph showing how developers work with versions of their repositories. It also has a service called Gist, where developers can distribute source code, similar to Paste Bin.

In 2008 – when the service was founded – it reached one million users, and in fewer than twelve months reached two million registered users. Now the service has reached three million users in fewer than six months. These events represent the service’s importance and popularity within the developer community.

GitHub adds collaborative features to Git, and best of all, offers them for free.

Note: a Git repository on GitHub is free if your repository is public. If you choose to make your project private, you’ll have to subscribe to one of the GitHub plans.

Prices start at 7.00 USD and can go up to 200.00 USD per month. If you’re looking for a tool that allows the use of Git and private repositories, how about getting to know BitBucket?

Various open-source projects use GitHub, such as jQuery, Perl, PHP, Zend Framework, Ruby and Joomla.
