PHP 5.4 Release

News João Paulo Cercal PHP 5.4 is fresh out of the oven. This version includes a large number of new features and bug fixes. Check out what's new. https://staging.jpcercal.com/pr-135/en/php-5-4-release/index.svg https://staging.jpcercal.com/pr-135/en/php-5-4-release/index.dark.svg en post

Hey folks! I’ve just seen, this very moment, that PHP 5.4 is fresh out of the oven, which you can check directly on the official PHP website.

This version includes a large number of new features and bug fixes. If you’re not familiar with PHP yet, read the following post: Introduction to PHP.

Among the main new features are:

  • Traits
  • Built-in web server
  • Better performance and reduced memory consumption
  • Small improvements in various extensions
  • Short Tags are now always available
  • Array dereferencing (being able to use square brackets on elements that return an array)
