Validating forms with the jQuery Validade plugin

Engineering João Paulo Cercal Learn to validate forms using an excellent plugin, get to know jQuery Validade developed by the team at http://bassistance.de. https://staging.jpcercal.com/pr-135/en/validating-forms-with-the-jquery-validade-plugin/index.svg https://staging.jpcercal.com/pr-135/en/validating-forms-with-the-jquery-validade-plugin/index.dark.svg en post

Today I introduce you to jQuery Validade, an excellent jQuery plugin developed by the team at http://bassistance.de.

You can download this plugin directly from the developer’s site (mentioned above) or from the GitHub repository (_https://github.com/jquery-validation/jquery-validation).

If you use GIT for version control, you can run the command below to clone the plugin’s official repository:

1

$ git clone https://github.com/jzaefferer/jquery-validation.git

To use this plugin you need to use jQuery.

Let’s get our hands dirty

Add the lines below inside the head tag of your HTML document.

1
2

<script type="text/javascript" src="js/jquery.min.js"></script>
<script type="text/javascript" src="js/jquery.validate.js"></script>

Now let’s create a form and add some fields. Check it out below:

  Confirmação de Senha: <input type="password" name="confirmar_senha" id="confirmar_senha" /><br />
  Termos de Contrato: <input type="checkbox" name="termos" id="termos"/><br />
  <input type="submit" value="Cadastrar" />
</form>

<script type="text/javascript">
$(document).ready(function(){
  $('#formulario').validate({
    rules: {
      nome: {
        required: true,
        minlength: 3
      },
      email: {
        required: true,
        email: true
      },
      senha: {
        required: true
      },
      confirmar_senha: {
        required: true,
        equalTo: "#senha"
      },
      termos: "required"
    },
    messages: {
      nome: {
        required: "O campo nome é obrigatório.",
        minlength: "O campo nome deve conter no mínimo 3 caracteres."
      },
      email: {
        required: "O campo email é obrigatório.",
        email: "O campo email deve conter um email válido."
      },
      senha: {
        required: "O campo senha é obrigatório."
      },
      confirmar_senha: {
        required: "O campo confirmação de senha é obrigatório.",
        equalTo: "O campo confirmação de senha deve ser identico ao campo senha."
      },
      termos: "Para se cadastrar você deve aceitar os termos de contrato."
    }
  });
});
</script>

Now just run your HTML document in your browser to see the final result.
