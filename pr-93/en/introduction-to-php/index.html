PHP, or Hypertext Preprocessor, is simply the most widely used server-side language on the web.

In 1994, thanks to its potential and simplicity, it gained wide acceptance in the webmaster community.

PHP allows easy integration with HTML markup. Numerous functions for exploring databases easily, without complications.

We could make the comparison that PHP and ASP are similar languages in terms of power and difficulty, although the syntax can differ considerably. Some main differences can still be mentioned:

  • PHP was initially designed for UNIX systems, although today it is cross-platform.
  • ASP is available only on Windows – especially NT – because it is a Microsoft technology.
  • PHP has a completely different philosophy and, with a more generous spirit, is gradually built by selfless contributors who implement new functions in new versions of the language.
  • ASP performs numerous tasks using components (objects) that the server must buy (or have programmed) from certain specialized companies.

In short, this little guide is intended for anyone who wants to start learning this language from scratch or who is looking directly to use it in personal website projects.

The chapters are quite simple, using clear language accessible to anyone unfamiliar with programming.

However, external sources may be needed for further clarification. The most important thing is to study the chapters step by step, don’t try to jump straight to the last chapter, don’t move on to another chapter if you haven’t understood it.
