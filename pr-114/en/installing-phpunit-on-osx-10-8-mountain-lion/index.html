Installing PHPUnit on OSX 10.8 Mountain Lion

Hello, today I’ll demonstrate how to install PHPUnit on Apple’s operating system. This guide should also be compatible with earlier operating systems in the apple family, such as Snow Leopard and Lion.

If you use the Microsoft Windows operating system, you can read this other tutorial: Installing PHPUnit on Windows.

Well, let’s install PHPUnit on OSX.

Open the Terminal and check whether PEAR is already installed with the following command.

1

$ pear version

If it isn’t installed, the command’s output should look like:

1

pear: command not found

If you saw that message, you should follow this tutorial before continuing with the PHPUnit installation: Installing PEAR on OSX 10.8 Mountain Lion.

Let’s continue the installation, open the Terminal and run the following command:

1

$ sudo pear config-set auto_discover 1

You’ll see a message like the one shown in the image below:

Once that’s done, you should run the following command in the terminal to install PHPUnit:

1

$ sudo pear install pear.phpunit.de/PHPUnit

PHPUnit was installed in the following directory: /Users/nome-do-seu-usuario/pear/share/pear/PHPUnit, to use it in your scripts, just include/check that your php.ini include_path already contains the PEAR directory.

To check this setting in your php.ini file, run the following command in the terminal:

1

$ cat /etc/php.ini | grep include_path

Your include_path will be displayed and should contain the following line:

/Users/nome-do-seu-usuario/pear/share/pear

If your include_path doesn’t have the line mentioned above, you should open the php.ini file and at the end of include_path add “:/Users/nome-do-seu-usuario/pear/share/pear” (without quotes).

class HelloWorldTest extends PHPUnit_Framework_TestCase
{
    public function testHelloWorld()
    {
        $obj = new HelloWorld();

        $this->assertEquals($obj->msg('Olá') , 'Olá');

Now run the test with the following command in the terminal:

1

$ phpunit teste-phpunit.php

An image like this will be displayed, reporting that all tests ran successfully.
