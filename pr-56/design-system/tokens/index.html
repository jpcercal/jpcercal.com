Spacing

Layout grid is Tailwind v4 with Bootstrap 5 breakpoints (sm 576px, md 768px, lg 992px) plus an exact-value grid-compat layer in assets/css/vendor.css (.row, .col*, .offset-*).

Content rhythm follows Bootstrap reboot parity inside .article-content: paragraphs, lists, quotes and code blocks get 1rem bottom margin, headings 0.5rem (see assets/scss/article.scss).
